GroupQuest для Windows

Потрібні Windows 10 або 11 (64-бітна версія для Intel чи AMD) і Google Chrome.
Python уже є в архіві. Окремо встановлювати його не потрібно.

1. На GitHub відкрий гілку groupquest-redesign-preview та вибери Code → Download ZIP.
2. Розпакуй весь ZIP, відкрий розпаковану папку і двічі клацни START.bat.
3. Chrome відкриє GroupQuest. Якщо вкладка не відкрилася, скопіюй адресу
   з вікна GroupQuest у свій Chrome. Це адреса сервера на твоєму ПК.
4. Залиш вікно сервера відкритим, поки граєш. Натисни Ctrl+C або закрий
   це вікно, щоб зупинити сервер.

Зазвичай використовується порт 4317. Якщо він зайнятий, сервер вибере
наступний вільний порт. Chrome зберігає прогрес окремо для кожної адреси.

Архів містить 11 ігор, обкладинки, JavaScript, CSS та шрифти.
Локальна версія має власні збереження у Chrome. Глобальний рейтинг
потребує серверного джерела даних. Інтеграція з Telegram доступна
під час запуску в Telegram.

Портативний Python 3.13.12 для Windows x64 взято з python.org.
Його ліцензія міститься у файлі runtime/LICENSE.txt.
